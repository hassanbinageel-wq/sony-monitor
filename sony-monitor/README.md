# 🎥 مونيتور Sony — تطبيق مراقبة وتحكم لكاميرات Sony عبر Wi‑Fi

تطبيق Android يحوّل هاتفك إلى **شاشة مونيتور تصوير** لكاميرات Sony عبر Wi‑Fi:
عرض حيّ + أدوات تعريض ولون احترافية + LUT للمعاينة + تحكّم والتقاط. مبني بطبقة
واجهة (HTML/CSS/JS + WebGL) فوق **مكوّن Android أصلي (Kotlin)** للاتصال والبث.

> **الجهاز المستهدف أولًا:** Samsung Galaxy S24. **الكاميرا الأولى:** Sony a7 III (ILCE‑7M3).

---

## ⚠️ حالة المشروع بصدق (اقرأها أولًا)

هذه **نسخة أساس (0.1)** قابلة للبناء وتنتج APK. ما يلي مصنّف بوضوح:

| الجزء | الحالة |
|---|---|
| بنية المشروع + بناء APK عبر GitHub Actions | ✅ جاهز |
| واجهة عربية RTL: وضعا مونيتور/تحكم، إخفاء الأزرار، أدلة التأطير، حفظ الإعدادات | ✅ يعمل على الهاتف |
| معالجة LUT (‎.cube) + Histogram/Waveform/Zebra/False Color/RGB Parade/Focus Peaking على GPU | ✅ يعمل على أي إطار وارد (جرّبها بـ«نمط الاختبار») |
| قياس FPS وزمن معالجة الهاتف | ✅ فعلي (لا أرقام مصطنعة) |
| طبقة اتصال Sony (SSDP + ScalarWebAPI + محلّل بث liveview + التقاط + إعدادات) | ✅ الكود ينفّذ البروتوكول — 🧪 **يحتاج تأكيدًا على كاميرتك** |
| البث الحي الحقيقي من a7 III + التقاط + إعدادات + ملفات | 🧪 **يجب اختباره على الكاميرا** (انظر `COMPATIBILITY.md`) |

**لا يوجد بثّ وهمي ولا نتائج مراقبة مصطنعة تُعرض كوظائف جاهزة.** «نمط الاختبار» في التطبيق
يظهر بشارة تحذير دائمة: «نمط اختبار — ليس بثًا من الكاميرا»، وغرضه فقط تجربة أدوات المونيتور
و LUT قبل توفّر الكاميرا.

تفاصيل ما هو مؤكَّد/يحتاج اختبارًا/غير مدعوم موجودة في **[COMPATIBILITY.md](COMPATIBILITY.md)**.

## 📦 كيف تحصل على ملف APK

### GitHub Actions (بدون تثبيت أي شيء)
1. ادفع المشروع إلى GitHub (يوجد ملف `.github/workflows/build-apk.yml`).
2. افتح تبويب **Actions** — يبدأ البناء تلقائيًا على الدفع، أو اضغط **Run workflow**.
3. بعد اكتمال البناء، حمّل `sony-monitor-apk` من قسم **Artifacts**.
4. فكّ الضغط ← ستجد `app-debug.apk`. انقله إلى Galaxy S24 وثبّته (فعّل «تثبيت من مصادر غير معروفة»).

### Android Studio (بديل)
افتح المجلد، دع Gradle Sync يكتمل، ثم **Build → Build APK(s)**.

## 🚀 خطوات الاختبار على الكاميرا والهاتف (a7 III + S24)

**على الكاميرا (a7 III):**
1. من قائمة الشبكة، فعّل **«التحكّم بالهاتف / Ctrl w/ Smartphone»** (Network → Ctrl w/ Smartphone → On).
2. اعرض معلومات الاتصال (SSID وكلمة المرور) من الكاميرا.

**على الهاتف (S24):**
3. من **إعدادات Android → Wi‑Fi**، اتصل بشبكة الكاميرا يدويًا باستخدام SSID/كلمة المرور.
   قد يظهر تنبيه «لا إنترنت» — هذا طبيعي؛ اختر البقاء متصلًا.
4. افتح تطبيق «مونيتور Sony»، وامنح إذن الموقع/الأجهزة القريبة (لازم لقراءة شبكة Wi‑Fi).
5. من لوحة **الاتصال 🔌** اضغط **«اتصال بالكاميرا»**.
6. سيقوم التطبيق بربط الشبكة → اكتشاف الكاميرا (SSDP) → قراءة قدراتها (`getAvailableApiList`)
   → بدء البث إن كان مدعومًا. ستظهر قائمة **«قدرات الكاميرا المكتشَفة»** بما يعمل فعلًا.
7. راقب مؤشّر **fps** و **ms** أعلى الشاشة للتأكد من وصول بثّ حيّ حقيقي.

**إن لم تتوفّر الكاميرا الآن:** فعّل **«مصدر الاختبار»** في لوحة الاتصال لتجربة LUT والأدوات على الهاتف.

### قياس التأخير «الزجاج إلى الزجاج» بصدق
لا يمكن قياس تأخير العرض الفعلي من ساعة الكاميرا. للقياس الحقيقي:
- صوّب الكاميرا على **مؤقّت/ساعة رقمية بالميلي ثانية** على شاشة أخرى، أو استخدم **وميض/تصفيق**.
- التقط صورة للشاشتين (الكاميرا الأصلية والهاتف) معًا، والفرق الزمني = التأخير.
- التطبيق يعرض **FPS وزمن معالجة الهاتف** فقط، ولا يزعم أن البث «لحظي».

│       ├── LiveviewParser.kt    # محلّل بث liveview (Common + Payload headers)
│       ├── StatusParser.kt      # قراءة getEvent (ISO/غالق/بطارية/تسجيل...)
│       └── CameraController.kt  # منسّق الاتصال/البث/التحكم/إعادة الاتصال
└── assets/www/                 # طبقة واجهة المونيتور (ويب)
    ├── index.html / css/style.css
    └── js/
        ├── gl.js               # محرّك WebGL2: LUT + Zebra/FalseColor/Peaking + قراءة الأدوات
        ├── lut.js              # محلّل ملفات ‎.cube ثلاثية الأبعاد
        ├── scopes.js           # Histogram/Waveform/RGB Parade من إطار المعاينة
        ├── overlays (داخل app.js) # أدلة التأطير/Safe Area/المرجع/القلب/التكبير
        ├── store.js            # حفظ LUTs/المشاريع/الإعدادات محليًا
        ├── testpattern.js      # نمط اختبار موسوم بوضوح

- **الاتصال والبث ونقل البيانات** في مكوّن Android أصلي (Kotlin + OkHttp).
- الأجزاء مفصولة: واجهة / اتصال كاميرا / معالجة مونيتور / تخزين.

## 🎨 ملاحظات LUT والألوان (مهمة)
- LUT هنا **للمعاينة على شاشة الهاتف فقط**، ولا يُطبَّق على صور/فيديو الكاميرا.
- البث الواصل قد يكون معالَجًا بالفعل بملف صورة الكاميرا (Picture Profile)، لذا قد يحدث
  تحويل لوني مزدوج — التطبيق ينبّه لذلك داخل لوحة LUT.
- زر «قبل/بعد» ومنزلق الشدّة (0–100%) لمقارنة عادلة.

## 📊 ملاحظات أدوات المراقبة
- كلها تُحسب من **إطار المعاينة المضغوط**، وقيمها تقريبية (0–100%) وليست وحدات مُعايَرة.
- يمكنك اختيار حساب الأدوات **قبل LUT** (الافتراضي — إشارة الكاميرا) أو **بعد LUT** (المعاينة).
- عند عدم موثوقية أداة على البث المتاح، تبقى النتيجة موصوفة بأنها تقريبية.
